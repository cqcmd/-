# 半整点提醒 · 使用说明书（门店/运维版）

## 1. 快速上手
1. 将 **`HalfHourChime.exe`** 复制到吧台管理机或工作终端的任意文件夹（如 `D:\Tools\HalfHourChime\`）。
2. **双击运行**后，程序会在右下角系统通知区域（托盘）显示一个蓝色圆环时钟图标，**任务栏不会出现多余窗口**。
3. **双击托盘图标**即可打开主状态窗口，查看当前时间、下一次报时/餐饮倒计时与校时状态。
4. 点击主窗口右上角 **`×`** 按钮不会退出程序，而是自动隐藏回托盘继续在后台报时；如需彻底关闭，请**右键托盘图标 → 点击“退出”**。

## 2. 常见配置操作
在主窗口点击 **“设置”** 或右键托盘选择 **“设置...”**，即可在一个面板内完成全部设置：
- **切换界面风格**：顶部支持一键切换 **暗夜曜石**（适合夜间吧台）、**晨曦云母**（Win11 清爽浅色）、**暖金咖啡馆**（低蓝光护眼）。
- **自定义报时分钟**：默认 `0, 30`（整点与半点各报时一次）。如需仅半点报时，改为 `30` 即可；如需每 15 分钟报时，填写 `0, 15, 30, 45`。
- **开启夜间静默时段**：打开静默开关并设置开始/结束时间（预设 `00:00` 至 `08:00`）。系统也支持跨天区间，例如 `23:00` 至次日 `07:00`。静默期间主窗口会醒目提示 **“静默中”** 且不播放报时音。
- **餐饮提醒**：开启开关并设定提醒时刻（预设 `12:00`，或点击快捷按钮一键设为 `12:00 午间` / `18:00 晚间`）。
- **音量调节与实时试听**：拖动 **0–100 音量滑块**时音量会**立即生效**，点击右侧 **“试听”** 可当场确认大小是否合适，无需先保存。
- **NTP 时间校时**：默认服务器为 `ntp.aliyun.com`。点击 **“立即校时”** 后，若系统需要管理员权限修改时钟，请在弹出的 Windows 授权窗口中点击 **“是”** 即可完成同步。
- **开机自启**：开启 **“开机自动启动”**（或在托盘右键菜单勾选），重启电脑后程序会自动隐身启动并常驻托盘。

## 3. 批量门店快速部署技巧
首次运行并保存设置后，程序会在同目录下自动生成 **`config.json`** 配置文件。  
如需给多台电脑配置完全相同的参数，只需在一台机器上调好设置并保存，然后将 **`HalfHourChime.exe` 与 `config.json` 一起拷贝到其他电脑**即可，免去重复设置。
