# 半整点提醒 · 使用说明书

## 1. 快速上手

1. 将 **`HalfHourChime.exe`** 放置到任意目录并双击运行，程序默认最小化驻留于系统右下角托盘。
2. **左键单击托盘图标**即可弹出主窗口，查看实时时间、运行状态与下一次提醒倒计时。
3. 点击主窗口右上角 **`×`** 会隐藏回托盘继续运行；彻底关闭请**右键托盘图标 → 退出**。

## 2. 功能设置

点击主窗口 **“设置与闹钟”** 或托盘右键 **“设置与闹钟...”** 可配置以下功能：

- **定时报时与节假日**：
  - 在 **「报时与节假日」** 页签可独立勾选 **整点 (:00)**、**半点 (:30)**，或填入额外分钟（如 `15, 45`）；全不选即进入纯闹钟模式。
  - 勾选 **节假日自动播报** 后，内置 2010–2040 公历/农历算法会自动识别传统与法定节假日并切换祝福问候。
  - 支持开启 **静默免打扰时段**（支持跨日，如 `23:00–07:00`），静默期间自动跳过整/半点报时。
- **自定义闹钟**：
  - 在 **「自定义闹钟」** 页签新建或一键添加常用预设（喝水提醒 / 起身活动 / 下班打卡）。
  - 支持 **仅一次、每天、工作日、周末、自定义星期、每隔 N 天** 等周期，以及专属提示音、本地音频和语音播报模板。
  - 闹钟到点弹出置顶提醒窗，可选择 **“停止并关闭”** 或 **“稍后 5 分钟再响”**；主面板与托盘右键均可随时打断正在进行的播报。
- **语音、主题与系统**：
  - 语音默认采用 **本地 Windows 语音（SAPI5）**，纯离线可用；如需神经网络音色可切换为 Edge 在线语音，离线时自动回退本地。
  - 支持 **暖金咖啡馆**、**暗夜曜石**、**晨曦云母** 三套主题实时切换，音量滑块拖动即时生效。
  - NTP 校时默认 `ntp.aliyun.com` 并内置国内多源容灾，也支持填写内网 NTP 服务器。
  - 可选开启 **本地 Web 控制台（3000 端口）** 在浏览器端同步管理与查看日志。

## 3. 配置备份与迁移

保存设置后程序会在同目录生成 **`config.json`**（只读目录时自动存至 `%APPDATA%\HalfHourChime\config.json`）。迁移电脑时将 **`HalfHourChime.exe` 与 `config.json` 一并复制**即可。
