# 半整点提醒 · 使用说明书

## 1. 快速上手
1. 将 **`HalfHourChime.exe`** 复制到电脑任意常用文件夹（如 `D:\Tools\HalfHourChime\`）。
2. **双击运行**后，程序会在右下角系统通知区域（托盘）显示一个蓝色圆环时钟图标，**任务栏不会出现多余窗口**。
3. **双击托盘图标**即可打开主状态窗口，查看当前时间、下一次报时或闹钟倒计时与校时状态。
4. 点击主窗口右上角 **`×`** 按钮不会退出程序，而是自动隐藏回托盘继续在后台运行；如需彻底关闭，请**右键托盘图标 → 点击“退出”**。

## 2. 常用配置与功能说明
在主窗口点击 **“设置与闹钟”** 或右键托盘选择 **“设置与闹钟...”**，即可完成全部个性化配置：
- **整点 / 半点 / 节假日勾选控制**：
  - 在 **「报时与节假日」** 标签页中直接勾选或取消 **“整点报时（每小时 :00）”** 与 **“半点报时（每小时 :30）”**，也可补充其他分钟（如 `15, 45`）；若两个都不勾选且未填额外分钟，则作为纯粹的定时闹钟使用。
  - 勾选 **“节假日自动播报”** 后，程序会根据内置 2010–2040 公历与农历历法自动识别法定节假日与传统节日，并自动切换到节日祝福语音与专属音效，无需联网接口。
- **自定义多组闹钟**：
  - 切换到 **「自定义闹钟」** 标签页，可点击 **“+ 新建闹钟”** 或使用快捷预设（**+ 喝水提醒**、**+ 起身活动**、**+ 下班打卡**）快速创建多个定时提醒。
  - 支持多种重复周期：**仅一次**（响铃一次后自动关闭开关，防止次日误响）、**每天**、**工作日（周一至五）**、**周末（周六/日）**、**自定义星期（任意勾选周一至周日）**、**每隔 N 天**。
  - 每组闹钟均支持独立开关、自定义标签、播前提示音、本地音频文件以及 **文字转语音播报**（支持 `{TIME}`、`{TIME12}`、`{PERIOD}`、`{LABEL}`、`{HH}`、`{MM}` 占位符），并可随时点击 **“试听”**。
  - 闹钟到点时会弹出置顶提醒卡片，可一键 **“停止并关闭”** 或 **“稍后 5 分钟再响”**；语音较长时也可在主界面或托盘右键点击 **“停止当前播报”** 随时打断。
- **切换界面风格**：支持一键切换 **暖金咖啡馆**（低蓝光护眼，默认）、**暗夜曜石** 与 **晨曦云母** 三套原生主题。
- **开启夜间静默时段**：打开静默开关并设置开始/结束时间（支持跨天区间，如 `23:00` 至次日 `07:00`）。静默期间自动跳过整/半点报时；自定义闹钟默认不受静默影响（防止早起闹钟被跳过），可在编辑闹钟时按需勾选遵循静默。
- **音量调节与实时试听**：拖动 **0–100 音量滑块**时音量会**立即生效**，点击 **“立即试听”** 即可确认音量与音色。
- **NTP 时间校时与开机自启**：默认使用 `ntp.aliyun.com` 校时；在设置页或托盘右键可开启 **“开机自启”**。

## 3. 配置备份与迁移
首次运行并保存设置后，程序会在同目录下自动生成 **`config.json`** 配置文件（若所在目录只读，则自动保存到 `%APPDATA%\HalfHourChime\config.json`）。  
如需在另一台电脑沿用相同闹钟与报时配置，只需将 **`HalfHourChime.exe` 与 `config.json` 一起拷贝过去**即可，免去重复配置。
